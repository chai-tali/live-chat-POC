# Avatar POC attribution

The avatar renderer is adapted from [DialogLab](https://github.com/ecruhue/DialogLab),
which includes Mika Suominen's [TalkingHead](https://github.com/met4citizen/TalkingHead)
under the MIT License.

The bundled GLB is a DialogLab demonstration asset created with Ready Player Me.
It is suitable for this evaluation only. Kyros must use an independently licensed
avatar asset before production deployment.
